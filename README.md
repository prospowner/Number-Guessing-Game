# Iterative Value Mutation Optimization Engine

An interactive string-parsing terminal game built in Python designed to track, shift, and dynamically adjust guess allocations based on user directional constraints.

## 🛠️ Engineering Concepts Applied
* **Algorithmic Value Scaling:** Features programmatic math steps to shift state thresholds upward or downward depending on directional inputs (`higher` / `lower`).
* **Complex Multi-Condition Filtering:** Processes conversational string flags using combined lookup structures (`in ANSWER.lower()`) to safely route system execution paths.
* **Telemetry and Analysis Pipelines:** Records execution loops inside a custom step tracker (`TRY`) to output efficiency matrices upon hitting the success criteria.
